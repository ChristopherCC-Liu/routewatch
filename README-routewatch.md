# RouteWatch

RouteWatch 是一个只读终端面板，用于汇总 Codex、Claude Code 和 Hermes 在本机记录的模型路由与 token 用量。

## 启动

```sh
routewatch
```

启动命令保持 `routewatch`。首屏立即打开，历史记录在后台加载。

## 交互视图

- **Overview 总览：**总 token、调用次数、缓存占比、最近速率、来源占比和主要路由。点击来源可筛选，点击趋势缩略图可进入分析视图。
- **Routes 路由：**滚动浏览完整列表，按 token、输出量、调用次数、最近活动或缓存量排序；搜索模型与 backend，回车展开完整详情。
- **Trends 趋势：**1 天窗口按本地今天的小时展示，其他窗口按日展示。左右移动游标或点击柱形，查看该小时/日的数值；可切换总量、prompt、输出、缓存和调用次数。
- **Sources 来源：**查看三种采集源的连接状态、最新用量时间、记录数量和速率。

| 操作 | 按键 |
|---|---|
| 切换视图 | `Tab` / `Shift-Tab`，或点击页签 |
| 时间窗口 | `1` 今天、`2` 7天、`3` 30天、`4` 90天 |
| 来源筛选 | `f` 循环切换 All / Codex / Claude Code / Hermes |
| 路由导航 | 上下方向键或 `j` / `k`，`PgUp` / `PgDn`，`Home` / `End` |
| 路由详情 | `Enter` 打开，`Esc` 或 `Enter` 关闭；鼠标双击也可打开 |
| 搜索与排序 | `/` 输入搜索，`Enter` 应用，`s` 切换排序，`x` 清空来源和搜索筛选 |
| 趋势游标与指标 | 左右方向键或 `h` / `l`，`m` 切换指标 |
| 暂停显示 / 恢复 | 空格（后台采集继续；切换时间或来源会恢复显示） |
| 手动刷新 / 帮助 / 退出 | `r` / `?` / `q` |

默认窗口为 30 天；1 天表示本地当天零点至现在。来源筛选同步作用于总览、路由和趋势；搜索仅过滤路由列表。来源诊断页始终展示三个来源。推荐终端尺寸至少 80×24，鼠标功能取决于终端支持。

查看一次文本快照：

```sh
routewatch --once
```

运行 `routewatch --help` 可更改来源目录、Hermes 数据库路径或刷新间隔。

## 数据来源与口径

- **Codex：**读取 `~/.codex/sessions/**/*.jsonl` 的逐次用量事件，并从会话上下文读取模型和 provider。
- **Claude Code：**读取 `~/.claude/projects/**/*.jsonl` 的 assistant 用量记录；同一条流式消息的重复记录会合并为最完整的一条。本地用量记录有模型名，但不含所用传输 provider，因此面板会显示“provider unknown”。
- **Hermes：**读取 `~/.hermes/state.db` 的模型用量汇总，并从 `~/.hermes/gateway_state.json` 获取 gateway 状态。
- 程序以只读方式解析本地日志，只提取用量和路由元数据，不展示或保存 prompt、回复内容、工具参数或密钥；不会联网，也不会改运行配置。
- Codex 和 Claude Code 的日趋势来自带时间戳的逐次记录。Hermes 按 session/model 保存累计用量，因此图表把整个 session 计入最后活跃日；跨来源逐日比较时需留意这个近似口径。
- Prompt 数包含来源单独记录的缓存 token。Cache 栏是其中的缓存部分，不会再次加进总量。
- 速率面板统计最近一分钟写入的已完成请求记录。本机数据源不提供生成过程中的实时流式 TPS。Hermes 速率从 RouteWatch 启动并观察到数据库增量后开始累计。

只依赖 Python 3 标准库，无需安装额外软件包。
